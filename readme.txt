Influencer affiliate program where partners split a fixed share of each sale between their own commission and a follower discount.

== Description ==
A fixed share of every sale is set aside. The partner decides how much of it is commission and how much is a discount for their followers; the store's cost stays the same. Coupon + link attribution, product-group shares, hold period, refund handling, monthly payouts with minimum and carry-over, partner panel in My Account, admin reports and e-mails. HPOS compatible, translatable (Turkish included).

== Installation ==
1. Activate the plugin (requires WooCommerce).
2. Configure WooCommerce > Settings > Affiliates.
3. Create a page with the [ssa_apply] shortcode and select it as the application page.
